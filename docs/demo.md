# Recording the demo / 录制演示

The checked-in `demo-placeholder.svg` is a **static placeholder**, not a recording. Replace the README image with `docs/demo.gif` after recording. The recording dependencies are development tools; `sheetdiff` itself stays a standalone offline binary.

仓库中的 `demo-placeholder.svg` 是**静态占位图，并非录制动图**。录制完成后，将 README 图片改为 `docs/demo.gif`。录制工具仅用于开发，不是 sheetdiff 的运行依赖。

Run commands from the repository root. Use a terminal/font with CJK glyphs for the Chinese fixtures.

以下命令在仓库根目录执行。终端字体需支持中文字符。

```sh
# Explicit regeneration rewrites only synthetic fixtures under tests/fixtures/.
# 显式重新生成合成测试数据。
cargo test --test fixtures regenerate -- --ignored
cargo build --release --locked

# Install VHS and its recording dependencies using its official instructions,
# then render the checked-in tape. This writes docs/demo.gif.
# 安装 VHS 后执行，输出 docs/demo.gif。
vhs scripts/demo.tape
```

The tape uses Bash and handles exit code 1 as an expected diff result. It shows a value change at B2, a formula change at C3, a format change at D1, row additions/deletions, sheet changes, and report export. Prebuilding avoids capturing the first compilation. If your system lacks DejaVu Sans Mono, choose another installed font in `scripts/demo.tape`; include a CJK fallback.

录制脚本使用 Bash，将“存在差异”的退出码 1 视为预期结果。演示包含 B2 值变化、C3 公式变化、D1 格式变化、行和 sheet 增删，以及报告导出。先构建可避免录入首次编译等待。若未安装 DejaVu Sans Mono，请将脚本中的字体改为已有字体并确保中文回退可用。

Alternatively, record an asciinema cast and convert it with `agg`:

也可以用 asciinema 录制，再用 agg 转为 GIF：

```sh
cargo build --release --locked
asciinema rec docs/demo.cast -c 'bash -c "./target/release/sheetdiff tests/fixtures/budget_v1.xlsx tests/fixtures/budget_v2.xlsx --context 0 --color always; rc=\$?; test \$rc -eq 1"'
agg docs/demo.cast docs/demo.gif
```

Recording output files can remain untracked until you choose to publish them. Open `target/demo.html` directly in a browser to inspect the offline report generated by the tape.

录制输出可暂不提交。脚本生成的 `target/demo.html` 可在浏览器中直接离线打开。

References / 参考：[VHS](https://github.com/charmbracelet/vhs), [asciinema](https://docs.asciinema.org/manual/cli/usage/), [agg](https://github.com/asciinema/agg).
